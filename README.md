# Portfolio Website - Aisyah Maryam Nurwulan

Website portofolio pribadi modern interaktif dengan efek glow dark mode.

## Tech Stack
- **HTML5** & **CSS3** (Custom Styling & Glassmorphism design)
- **JavaScript (Vanilla)** (Interactive modal dialog & dynamic contents)
- **Lucide Icons** (Vector icons)

## Cara Menjalankan Secara Lokal
1. Download atau clone repository ini.
2. Buka file `index.html` langsung melalui browser pilihan Anda.
